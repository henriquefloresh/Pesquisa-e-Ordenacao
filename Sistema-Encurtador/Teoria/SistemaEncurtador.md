## Sistema pra Encurtador

1. Entrar no link Orignal: www.ufn.edu.br hashCode()
2. Gerar Hash (positivo) do link Original
3. Armazenar em HASHMAP:
   - chave: hash gerado
   - conteudo: Link original; cliques
4. Devolver link encurtador
5. Acessar o link encurtado
   - informar o link encurtado
   - pesquisar hashmap pelo hash
   - Devolver link original
